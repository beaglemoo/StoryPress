# Asset provenance

`storypress-app-icon-original.png` is the original StoryPress book-and-moon icon artwork generated for this project. The app icon variants in `StoryPress/Assets.xcassets/AppIcon.appiconset/` are size-reduced PNG copies of that original.

`SamplePath`, `SamplePond`, and `SampleDen` are original sample-book illustrations generated specifically for StoryPress with the OpenAI image-generation tool on 2026-09-24. The image files in the asset catalog are size-reduced copies. The sample art is not generated by a local Qwen model and is not user-uploaded content.
