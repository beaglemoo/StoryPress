# StoryPress v0.1.0 Preview

StoryPress is a native macOS 26+ picture-book editor with SwiftUI and Liquid Glass controls. Create editable books, plan a story with a chosen provider, generate illustrations with a separately chosen image provider, and export a printable PDF.

## What is included

- An offline sample book for exploring the editor without connecting to a provider.
- Editable title, story text, character description, and page illustration prompts.
- Separate local or cloud choices for story planning and image generation.
- Reference artwork import, page-by-page image retry, and selectable narration in exported PDFs.
- Local storage for books and artwork.

## Install

Download the signed and notarized universal macOS ZIP attached to this release. It supports macOS 26 or later and contains arm64 and x86_64 app binaries. Open the ZIP, move StoryPress.app to Applications, then launch it.

StoryPress does not include model weights or model servers. Local generation requires a separately installed and running compatible service. OpenRouter cloud use requires an account and API key; providers may charge for requests. Story and image providers remain independent, and StoryPress does not switch to a cloud service automatically.

## Validation and limits

The release passed 23 core unit tests and 2 focused PDF checks. The signed app completed a live three-page oMLX story with ComfyUI/Qwen Image 2.1 illustrations and exported a four-page A4 PDF with selectable text and visually reviewed pages. A live three-page DwarfStar story-planning check also passed. OpenRouter model discovery and mocked request tests passed; paid live OpenRouter generation was not tested.

The universal build was verified on arm64 hardware. The x86_64 app slice was not run on Intel hardware. Generation speed and output quality depend on the selected model, service, workflow, and hardware. StoryPress does not automatically review images or guarantee character consistency; review and edit the book before printing.
